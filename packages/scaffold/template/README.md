# __HOMEFRAME_APP_NAME_MARKDOWN__

A Homeframe React PWA generated by `scaffold-homeframe-app`.

## Start developing

```bash
npm install
npm run dev
```

The scaffold intentionally separates product UI from framework-owned browser
behavior. Before changing layout, routing, installation metadata, service-worker
behavior, inputs, safe areas, or keyboard handling, read [AGENTS.md](./AGENTS.md)
and [docs/HOMEFRAME_RUNBOOK.md](./docs/HOMEFRAME_RUNBOOK.md).

## Commands

- `npm run dev` starts Vite on the local network.
- `npm run typecheck` checks strict TypeScript.
- `npm run build` typechecks and creates the production PWA.
- `npm run doctor` audits the source and built output against Homeframe rules.
- `npm run check` runs the release-oriented build and doctor checks.

## Project map

- `homeframe.config.ts` owns app identity, generated browser metadata, viewport
  policy, router policy, install nudges, and service-worker updates.
- `src/App.tsx` composes the one Homeframe viewport, application shell, internal
  scroller, router, and product-owned pages.
- `src/styles.css` styles surfaces inside the Homeframe shell.
- `brand/icon.svg` is the source for generated install and startup assets.
- `AGENTS.md` gives coding agents concise non-negotiable rules.
- `docs/HOMEFRAME_RUNBOOK.md` is the implementation and release runbook.

## Before production

Replace the starter identity and icon without changing `id`, `scope`, or the
worker URL after users install the app. Then run:

```bash
npm run check
npm run dev
```

Test the built app over HTTPS in iOS Safari, as an installed iOS Home Screen app,
in desktop Chrome/Safari, and as an installed desktop PWA. The runbook contains
the full acceptance checklist.
